# Правила участия в CTF-Starter

Спасибо, что хочешь помочь проекту! Это руководство объясняет, как сделать свой вклад максимально полезным.

## Кодекс участника

- Будь вежлив и уважителен к другим участникам
- Здесь нет глупых вопросов — мы все когда-то начинали
- Не публикуй полные решения задач с активных CTF-соревнований
- Критикуй идеи, а не людей

## Как предложить изменение

### Небольшие правки (опечатки, ссылки)
Просто открой Pull Request с описанием изменения.

### Новый контент (раздел, инструмент, задача)
1. Сначала открой Issue с описанием идеи
2. Дождись обратной связи
3. Создай Pull Request со ссылкой на Issue

### Подсказки к задачам
Добавляй подсказки в папку `hints/<категория>/`. Формат файла:

```markdown
## Название задачи / платформа

**Уровень:** Easy / Medium / Hard  
**Категория:** Web / Crypto / ...

### Подсказка 1 (лёгкая)
Попробуй посмотреть на заголовки HTTP-ответа...

### Подсказка 2 (если застрял)
Обрати внимание на параметр `id` в URL...

### Ключевые инструменты
- `curl -I url`
- BurpSuite
```

## Нашёл ошибку?

Открой Issue с тегом `bug` и опиши:
- Где ошибка (ссылка на файл/раздел)
- В чём проблема
- Как должно быть правильно

## Предложения

Открой Issue с тегом `enhancement` и опиши:
- Что предлагаешь добавить
- Почему это полезно для новичков
- Есть ли у тебя готовые материалы?

## Чеклист перед Pull Request

- [ ] Текст написан понятным языком (проверь на знакомом, который не знает ИБ)
- [ ] Нет орфографических ошибок
- [ ] Ссылки рабочие
- [ ] Нет полных спойлеров к задачам
- [ ] Файл в правильной папке
