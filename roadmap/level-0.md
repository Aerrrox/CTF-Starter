# Уровень 0 — Старт с нуля

> Этот раздел для тех, кто никогда не участвовал в CTF и хочет понять, с чего начать.

## Что такое CTF?

**Capture The Flag** — это соревнование по информационной безопасности, где участники решают задачи и находят скрытые строки (флаги) вида `FLAG{что-то_секретное}`.

Задачи бывают разных категорий:
- **Web** — взаимодействие с веб-приложениями
- **Crypto** — шифрование и криптография
- **Forensics** — анализ файлов и данных
- **OSINT** — поиск по открытым источникам
- **Steganography** — скрытая информация в файлах
- **Reverse Engineering** — анализ программ
- **Pwn** — эксплуатация уязвимостей

## Шаг 1 — Настрой окружение

### Минимальный вариант (для начала)
- Браузер + расширение **Wappalyzer**
- [CyberChef](https://gchq.github.io/CyberChef/) — онлайн-инструмент для декодирования
- [dcode.fr](https://www.dcode.fr/) — определение и расшифровка шифров

### Полноценное окружение
- **Kali Linux** или **Parrot OS** — дистрибутивы с предустановленными инструментами
- Можно запустить в виртуальной машине (VirtualBox / VMware) или WSL2 на Windows

---

## Шаг 2 — Изучи базовые концепции

### Linux командная строка (обязательно!)
Без этого никуда. Начни с [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) — это игра-туториал по Linux через SSH.

Базовые команды:
```bash
ls, cd, cat, grep, find, file, strings, xxd
```

### Кодирования и форматы данных
Это встретится в каждой второй задаче:

| Формат | Пример | Инструмент |
|--------|--------|-----------|
| Base64 | `SGVsbG8=` | CyberChef, `base64 -d` |
| HEX | `48 65 6c 6c 6f` | CyberChef, `xxd` |
| ASCII | 72 = 'H' | Таблица ASCII |
| Binary | `01001000` | CyberChef |
| ROT13 | `Uryyb` | CyberChef |

### Основы сетей
- Что такое IP-адрес, порт, протокол
- HTTP: запрос/ответ, заголовки, методы GET/POST
- DNS: как работает разрешение имён

## Шаг 3 — Реши первые задачи

### Рекомендуемый порядок

**Неделя 1–2:** [picoCTF](https://picoctf.org)
- Раздел "Practice" → сортировка по сложности
- Начни с General Skills и Cryptography (Easy)

**Неделя 3–4:** [OverTheWire Bandit](https://overthewire.org/wargames/bandit/)
- Уровни 0–15 дадут отличную базу по Linux

**Месяц 2:** [TryHackMe](https://tryhackme.com)
- Комнаты "Pre-Security" и "Introduction to Cybersecurity"

3. Поищи writeup аналогичной задачи (не копируй — пойми логику!)
