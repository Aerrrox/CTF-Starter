## О проекте

**CTF-Starter** — это открытый образовательный ресурс для тех, кто хочет войти в мир Capture The Flag соревнований, но не знает, с чего начать.

### Проблема
Большинство материалов по CTF рассчитаны на уже опытных участников. Новичок, впервые столкнувшийся с задачами по ИБ, часто не понимает:
- В каком порядке учиться?
- Что вообще нужно знать?
- Где найти задачи своего уровня?
- К кому обратиться с вопросом без страха осуждения?

### Решение
Структурированный роадмап с задачами, разбитыми по уровням сложности, открытый форум вопросов и система краудсорсинга подсказок от сообщества.

---

## Для кого этот проект

- Студенты технических специальностей, интересующиеся ИБ
- Новички, которые впервые слышат слово «CTF»
- Те, кто пробовал участвовать в CTF, но застрял и бросил
- Преподаватели, ищущие структурированный материал для курсов по ИБ

## Роадмап по уровням

### Уровень 0 — Основы (совсем с нуля)
Необходимые знания до первой CTF-задачи.

| Тема | Что изучить | Ресурсы |
|------|------------|---------|
| Linux CLI | Базовые команды, файловая система | `man`, `tldr`, overthewire.org/wargames/bandit |
| Сети | IP, TCP/UDP, HTTP, DNS | Wireshark для начинающих |
| Кодирование | Base64, HEX, ASCII, бинарный код | CyberChef |
| Python basics | Скрипты, работа со строками и байтами | Python.org tutorial |
| Инструменты | Kali Linux / Parrot OS, установка окружения | — |

### Уровень 1 — Первые задачи (Easy)
Категории задач, с которых стоит начинать.

| Категория | Описание | Пример инструментов |
|-----------|---------|---------------------|
| **OSINT** | Поиск информации по открытым источникам | Google dorks, Shodan |
| **Steganography** | Скрытая информация в файлах | Steghide, Binwalk, ExifTool |
| **Crypto (классика)** | Шифр Цезаря, Виженер, XOR | CyberChef, dcode.fr |
| **Forensics (basic)** | Анализ файлов, метаданные, HEX-редакторы | HxD, 010 Editor |
| **Web (intro)** | Источник страницы, cookies, базовый SQL | BurpSuite Community |

### Уровень 2 — Уверенный новичок (Medium)

| Категория | Описание |
|-----------|---------|
| **Reverse Engineering** | Дизассемблирование, базовый анализ бинарников |
| **Pwn (basic)** | Buffer overflow, базовая эксплуатация |
| **Crypto (modern)** | RSA, хэш-функции, padding oracle |
| **Web (intermediate)** | XSS, SSRF, LFI/RFI, JWT |
| **Forensics (network)** | Анализ PCAP, восстановление трафика |

## Краудсорсинг подсказок

Застрял на задаче? Или решил что-то интересным способом?

👉 **[Открыть новое обсуждение](../../discussions/new)**

### Правила форума подсказок
1. **Не спойлерь полное решение** — давай наводящий вопрос или направление
2. Укажи **категорию** и **уровень** задачи
3. Опиши, что ты **уже попробовал**
4. Будь вежлив — здесь нет глупых вопросов
5. Если получил помощь — отметь ответ как решённый

### Формат вопроса
```
Категория: Web / Crypto / Forensics / OSINT / Pwn / Rev / Stego / Other
Уровень: 0 / 1 / 2 / 3
Платформа и название задачи: ...
Что попробовал: ...
Вопрос: ...
```

## Как участвовать в проекте

Это краудсорсинговый проект — он развивается благодаря сообществу!

### Что можно сделать прямо сейчас

| Вклад | Как |
|-------|-----|
| Задать вопрос | [Discussions → Q&A](../../discussions) |
